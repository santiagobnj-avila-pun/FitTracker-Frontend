# FitTracker - Frontend

## Fit Tracker

Aplicación web para organizar rutinas de entrenamiento, consultar ejercicios, planificar sesiones y realizar un seguimiento del progreso.

### Descripción

Fit Tracker permite consultar un catálogo de **48 ejercicios**, realizar búsquedas, aplicar filtros, guardar favoritos y ver detalles.

También permite **crear, editar, duplicar y eliminar rutinas**, personalizar series, repeticiones, cargas y descansos, y programarlas en un calendario.

Durante los entrenamientos se registran las series realizadas y se actualizan las métricas, récords e historial. También incluye un temporizador para los descansos.

El perfil funciona de forma local mediante **localStorage**. Las rutinas, sesiones y planificación se guardan únicamente en el navegador actual. No cuenta con login seguro, base de datos ni sincronización entre dispositivos. Los datos pueden descargarse en formato JSON.

Las plantillas son ejemplos editables y no representan planes profesionales personalizados.
